# Reading and acting on a report

Use the report as a queue for human review. Its counts describe the supplied inventory, not the wider web or an entity's authority.

| Observation | Useful next action |
| --- | --- |
| Missing evidence | Locate sources or narrow/withdraw the public claim. No evidence in this file does not prove the claim false. |
| Unreviewed | Read the source and record a support declaration with a rationale. |
| Partial | Identify exactly what is supported; split a compound claim if needed. |
| Supporting sources | Revisit the source and its context before publishing a consequential claim. |
| Conflicting sources | Review contrary evidence explicitly, reconcile dates/context, and retain the audit trail. Supporting rows do not resolve conflict. |
| Zero independent supporting publishers | Review relationships and coverage. Owned evidence may still be useful but is not independent support. |
| Stale review age | Reopen the source to see whether it changed; retain valid historical evidence. |
| Unknown review age | Record the actual access date when a reviewer checks the source. Do not invent one. |

In the fictional sample, Mira Vale's chair claim has supporting and contrary declarations at the same time. Two supporting URLs share one normalized publisher, so they count as one declared independent supporting publisher. Northstar Civic Lab's research claim has owned support, partial unknown-relationship evidence and an unreviewed URL; none raises the independent support count. Its office claim has no evidence rows.

For public communications, distinguish what a source states, what the reviewer concluded and what remains unresolved. Do not describe these reports as verified audits, certifications, search ranking forecasts or proof of institutional endorsement.
